## IHE Technical Frameworks General Introduction Appendix A: Actors

| Proposed actor | Definition |
|---|---|
| [De-Identification Requester](volume-1.html#de-identification-requester) | Submits an authorized de-identification job and receives or retrieves the result. |
| [De-ID Manager](volume-1.html#de-id-manager) | Validates and coordinates de-identification jobs and manages the release of results. |
| [De-Identifier](volume-1.html#de-identifier) | Executes assigned de-identification tasks and returns their results and evidence. |
| [Integrated De-ID Manager/De-Identifier](volume-1.html#integrated-de-id-manager-de-identifier) | Combines job management and task execution in a single actor. |
{: .grid}

See [Appendix A](https://profiles.ihe.net/GeneralIntro/ch-A.html) for the actor index.

## IHE Technical Frameworks General Introduction Appendix B: Transactions

| Proposed transaction | Definition |
|---|---|
| [Submit De-Identification Job (ITI-x1)](volume-2.html#23x1-submit-de-identification-job-iti-x1) | Submits a job under an approved data request and policy. |
| [Submit De-Identification Task (ITI-x3)](volume-2.html#23x3-submit-de-identification-task-iti-x3) | Dispatches an execution plan and its processing targets to a De-Identifier. |
| [Retrieve Job Output (ITI-x4)](volume-2.html#23x4-retrieve-job-output-iti-x4) | Retrieves status or output for an asynchronous job. |
| [Retrieve Task Output (ITI-x7)](volume-2.html#23x7-retrieve-task-output-iti-x7) | Retrieves status or output for an asynchronous task. |
{: .grid}

The transaction identifiers remain provisional. See [Appendix B](https://profiles.ihe.net/GeneralIntro/ch-B.html) for the transaction index.
